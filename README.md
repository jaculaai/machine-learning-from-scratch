# Machine Learning From Scratch 🧠

Implementacja fundamentalnych algorytmów Machine Learning od zera (bez użycia bibliotek typu scikit-learn). 

## 🎯 Cel projektu
Celem tego repozytorium jest dogłębne zrozumienie matematyki i logiki stojącej za najpopularniejszymi algorytmami ML. Zamiast korzystać z gotowych rozwiązań, zaimplementowałem je przy użyciu wyłącznie NumPy, aby zrozumieć, jak naprawdę "myśli" model.

## 🛠️ Zaimplementowane algorytmy
- [ ] Linear Regression (Gradient Descent)
- [ ] Logistic Regression
- [ ] K-Nearest Neighbors (KNN)
- [ ] ... (tu wpisz co dokładnie masz)
